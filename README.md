# Eon's Insomnium

_Eon's Insomnium_ è un progetto indie dedicato a creare esperienze immersive e psichedeliche. Il gioco unisce meccaniche run-and-gun con atmosfere oniriche e narrative profonde, progettate per coinvolgere i giocatori in un mondo unico e disturbante.
